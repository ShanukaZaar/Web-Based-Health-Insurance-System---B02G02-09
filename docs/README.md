# Documentation Directory

This directory stores project design artifacts, software requirement specifications (SRS), system architecture diagrams, database ER diagrams, and UML diagrams for the **Web-Based Health Insurance Management System** (SLIIT SE2030).

## Expected Documents
- `architecture-diagram.png` / `.pdf`: Overall system architecture diagram.
- `er-diagram.png`: Database Entity-Relationship diagram.
- `usecase-diagram.png`: System use case diagram.
- `api-specification.md`: Detailed OpenAPI / Swagger REST API endpoint specifications.
